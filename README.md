# meal-plan-tracker
A simple web app for tracking swipes and Flex allowance on and around the Grace College campus

## Installation
1. Clone the repository
2. Open a terminal in the `meal-plan-tracker` directory
3. Run `python -m venv .venv` to create a virtual environment
4. Activate the virtual environment
    - For Windows, run `.venv\Scripts\activate`
    - For Unix systems, run `. .venv/Scripts/activate`
5. Run `pip install -r requirements.txt` to install the prerequisites
6. Run `python -m flask --app main run` to start the server
